## BLOCKER 1 — Portfolio optimiser returns equal-weight seed on small-magnitude covariance

- **Severity:** blocker (numerical correctness, silent wrong result)
- **Domain / branch:** portfolio / `feat/p5-val-portfolio`
- **Files:** `engine/portfolio_optimisation.py`
  — `minimum_variance_portfolio` (`allow_short=False`), `risk_parity_portfolio`
- **Suggested branch to fix:** `fix/portfolio-slsqp-convergence`

### Symptom
With a realistic **per-period** (small-magnitude, ~1e-4 scale) covariance matrix,
both optimisers return the equal-weight starting point `[1/3, 1/3, 1/3]` instead
of optimising.

Reproduction (well-conditioned 3-asset cov, sd=[0.02,0.015,0.03], corr 0.3/-0.1/0.2):

```
closed-form long/short min-var w = [0.3084 0.5439 0.1478]  var = 1.634e-04
engine  long-only      min-var w = [0.3333 0.3333 0.3333]  var = 1.961e-04   (= equal weight)
risk-parity engine     w = [0.3333 0.3333 0.3333]  risk-contrib = [0.244 0.229 0.527]  (target 0.333 each)
```

Deviation: min-variance ~20% higher variance than optimal; risk-parity largest
risk contribution 0.527 vs 0.333 (~58% off). Exceeds the 0.1% tolerance.

### Root cause
SLSQP declares convergence after ~1 iteration because the variance-only objective
gradient is below the default `ftol` when the covariance is ~1e-4 scale and the
search starts from the equal-weight seed. `mean_variance_optimisation` is NOT
affected because its return term keeps the gradient above `ftol`.

### Fix direction (not applied — engine not edited during validation)
Tighten SLSQP `ftol` and/or scale the objective (e.g. multiply variance by 1e4),
or use a multi-start, in the two affected wrappers. Re-enable the two `xfail(strict)`
tests in `tests/validation/test_portfolio_ref.py` once fixed.

### Test evidence
`tests/validation/test_portfolio_ref.py`:
- `test_minimum_variance_le_equal_weight_variance` — `xfail(strict)`
- `test_risk_parity_equal_risk_contribution` — `xfail(strict)`
Both assert against independent closed-form / multi-start references (not the
function's own output). Independently reproduced by the lead.
