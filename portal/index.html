api reference

Simple async
job pattern.

All 385 functions use the same async job pattern: POST to submit, GET to poll. No timeouts, no blocking — designed for 100k-path Monte Carlo simulations running 2–10 seconds.

core endpoints
POST
/api/v1/{domain}/compute
Submit job · returns task_id immediately
GET
/api/v1/{domain}/result/{task_id}
Poll result · pending → started → success
GET
/api/v1/domains
List all 8 domains and function catalogue
GET
/health
