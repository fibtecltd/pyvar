# pyvar-arch-api-gateway

Arch: FastAPI, Pydantic v2, JWT and API-key auth, orjson, rate limiting, OpenAPI.

A Claude skill with architecture notes for contributors to the pyvar codebase (https://github.com/fibtecltd/pyvar). It is not needed to call the pyvar API.

## Install

```
/plugin marketplace add fibtecltd/pyvar
/plugin install pyvar-arch-api-gateway@pyvar-marketplace
```
